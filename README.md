Para abrir correctamente el proyecto entero:
1. Descargar y extraer el ZIP completo de GitHub.
2. Abrir Unity Hub.
3. Seleccionar “Add Project”.
4. Elegir la carpeta:
CARPETA CON PROYECTO ENTERO
Importante:
La carpeta debe contener directamente: Assets, Packages y ProjectSettings
Si aparece algún error al abrir:
1. Cerrar Unity.
2. Borrar las siguientes carpetas que tiene dentro ‘CARPETA CON PROYECTO
ENTERO’:
○ Library
○ Temp
○ obj
3. Volver a abrir el proyecto. Si aparecen errores antiguos en la consola de
Unity, puede pulsarse el botón “Clear” para limpiar la consola y visualizar
únicamente los errores actuales del proyecto, si aún los hay.
Las carpetas Library, Temp y obj no se incluyen porque Unity las genera
automáticamente al importar un nuevo proyecto.
